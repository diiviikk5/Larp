Memory that agents share

Every Larp install gets agent memory with no setup: agents recall what they learned before a task, leave notes for each other, and keep lessons people approved. Each of those is a call to Meko, logged in YugabyteDB. These are the real numbers, refreshed every few seconds. Counts only: nobody's tasks or memories are shown.

How it works

  1. Recall. Before an agent starts, Larp searches Meko (context_search) for what that agent, and its space, learned before.
  2. Remember. After a task, what the agent did and what the reviewer said goes back in (memory_add).
  3. Hand off. When one agent asks another for help, the answer is left as a note in the other agent's memory.
  4. Lessons. A lesson a person approves is promoted (memory_promote) so every agent in the space knows it.
  5. Proof. Each result's diff is stored as a content-addressed artifact (artifact_put).
  6. History. Every call, event and the space's state go to YugabyteDB, so the history outlives any one computer.

Larp Cloud holds the keys, so installs don't. Each Larp gets its own team, and teams never see each other's memories. Prefer your own? Put a MEKO_API_KEY or YUGABYTE_URL in Larp's .env, or LARP_CLOUD=off to keep everything on your computer.
